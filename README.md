
# KMEANS - RANDOM FOREST

Ứng dụng Machine Learning phân cụm và dự đoán chất lượng rượu vang đỏ.

## Thuật toán
- K-means: Phân cụm dữ liệu.
- Elbow Method: Tìm số cụm phù hợp.
- PCA: Trực quan hóa các cụm.
- Random Forest: Dự đoán chất lượng rượu vang.

## Thuộc tính đầu vào
- fixed acidity
- total sulfur dioxide
- pH
- alcohol

## Nhãn dự đoán
- quality

pip install -r requirements.txt
